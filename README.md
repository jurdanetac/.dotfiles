# dotfiles
Personal configuraton files for my Mac, managed with GNU Stow. Under continuous revision and improvement.

## List of configs
- Emacs
- Homebrew
- Zsh / Oh My Zsh!
- Vim

## Usage
```
$ git clone git@github.com:jurdanetac/dotfiles.git ~/dotfiles
$ cd ~/dotfiles
$ stow emacs homebrew zsh vim
```
